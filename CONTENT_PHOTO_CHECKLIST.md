# Project photo checklist

The two new case studies use purpose-built diagrams until the real photographs are added.

## Electric dirt bike importing

- One strong landscape shot of a complete bike for the case-study cover
- Sur-Ron Light Bee X and Talaria Sting MX4 together, if a photo exists
- Close-up of the Chinese-language display or controls
- Arrival, crate or unpacking photo
- Riding photo that feels candid rather than staged
- Optional sourcing document or freight label, with personal and supplier details hidden

Suggested folder: public/images/photos/ElectricDirtBikes/

## Printbot

- Production dashboard at desktop width
- A search request with Printables and Thingiverse results
- Slicer preview showing orientation and supports
- Printer status while a job is running
- String-art input, solved preview and finished physical piece
- Shopify order beside the resulting production job
- A wider photograph of the printer farm

Suggested folder: public/images/photos/Printbot/

## When the files are ready

1. Put the originals in the folders above.
2. Run npm run images:optimize.
3. Add the resulting paths to each project's gallery in src/content/cv.ts.
4. Use the strongest landscape image as the first gallery item.
5. Check both case studies on mobile before publishing.
